# 当前功能状态

本文件描述当前交付；最新开发顺序与需求取舍见 [ROADMAP.md](ROADMAP.md)。

2026-10-16：右侧属性栏只在打开文章时出现。文章列表页不再占用右栏显示「选择一篇内容」占位，列表和统计视图使用整行宽度。编辑器里的属性栏左边缘垂直中央有一个收缩手柄，收起后手柄停在窗口右边缘，箭头随之翻转，可以再展开。

2026-10-16：正文编辑器提供「撤回为草稿」。它把文章和同名图片目录从 `src/contents/post` 移到 `src/contents/drafts`，与「发布到正文」共用同一套移动、冲突检查和回滚逻辑，只是方向相反。草稿列表、正文列表和 AI 日报不会出现方向不对的按钮。

2026-10-14：文章编辑器提供「编辑模式」和「源码模式」。`.md` 默认进入编辑模式（Muya 所见即所得）；`.mdx` 只进入源码模式。两种模式编辑同一份 Markdown 正文，Frontmatter 原样拼回。Muya 仍由稳定的 React 外层节点承载内部挂载点，避免开发模式重复挂载后正文空白。

未实现：克隆、属性可视化编辑、删除后的应用内恢复、自动保存到文章文件、生产构建、月度趋势、热力图、访问量、Git fetch / commit / merge / push、部署状态接入、安装包完整验收。这些功能没有假按钮或模拟成功。

AI 日报不支持新增，也不导入图片。已有日报可使用编辑模式和源码模式。发布到正文和撤回为草稿都只改变本地目录：前者不表示线上已经发布，后者也不代表线上已经移除，两者都不提交 Git。

保存内容始终是原始 Frontmatter 加上当前统一正文。Frontmatter 原文、注释、未知字段、日期、引号、字段顺序、BOM 和换行风格保留。进入编辑模式时，Muya 可能规范化正文（空格、空行、列表标记等）；只有正文确实变化才标记未保存，仅换行符不同不算修改。属性栏显示已保存版本。两种模式都不编辑 Frontmatter，改 YAML 需使用外部编辑器。`.mdx` 不能进入编辑模式，也不执行其中的组件或表达式。完整站点效果使用顶栏「本地预览」，说明见 [本地预览](PREVIEW.md)。S3/R2 凭据存在用户数据目录的 `image-storage.json`，不进入 `settings.json`，界面不回显秘密密钥。上传失败不插入链接，也不改存本地。编辑恢复在停止输入 600 ms 后写入客户端目录，不等于保存文章；异常退出前尚未写入恢复记录的最后输入无法保证恢复。细节见 [编辑与恢复](EDITOR.md)。

正文、草稿和日报由目录区分，互不替代。`post` 里即使写了 `draft: true` 仍是正文，`drafts` 里即使是 `draft: false` 或没有该字段仍是草稿。正文不表示已经发布到线上。新建文件名兼容 Windows，标题中的路径分隔符不作为目录处理；写入前复核当前项目及草稿目录，拒绝目录链接。目录不存在时，只在已授权项目内创建 `src/contents/drafts`。先完整写入并同步临时文件，再用不覆盖目标的硬链接完成创建，因此需要支持硬链接的文件系统（本机 NTFS 已验收）。不改写已有文章里的 draft 字段，也不按该字段批量搬迁文件；客户端没有自动提交或推送博客的能力。
