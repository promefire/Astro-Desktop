# 当前功能状态

本文件描述当前交付；最新开发顺序与需求取舍见 [ROADMAP.md](ROADMAP.md)。

| 模块 | 当前范围 |
| --- | --- |
| 项目初始化 | Electron / React / TypeScript strict / Vite / Tailwind，Main / Preload / Renderer 分层 |
| 桌面 UI | 欢迎、文章、正文、草稿、AI 日报、文章统计、项目设置路由；主区编辑器与右侧已保存属性 |
| 项目接入 | Windows 原生目录选择，Astro / collection / Git 检查，最近项目及恢复 |
| 内容读取 | 按目录读取正文 `post`、草稿 `drafts`、AI 日报 `ai-daily`；Frontmatter 的 draft 字段只保留为元数据 |
| 日报 | 独立 summary / highlights / tools / tags；无草稿控制 |
| 浏览 | 搜索、分类 / 标签筛选、排序和分页，资源管理器定位 |
| 源码编辑 | CodeMirror 6，Markdown / YAML 高亮、行号、折叠、查找替换、撤销重做；源码 / 基础预览 / 可调整左右分栏 |
| 保存与恢复 | Ctrl+S / 按钮真实保存；SHA-256 版本检查、临时文件同步与替换、保存前本地备份；未保存导航 / 关闭提示、恢复记录、导出副本 |
| 外部编辑器 | 用 Windows 为 .md / .mdx 登记的默认程序打开当前文章，不需要手动选择。未保存内容需先保存或放弃。打开后编辑区暂停并显示重新加载引导；外部修改不会自动进入编辑器，保存仍检测冲突 |
| 本地预览 | 在当前博客目录执行真实 `npm run dev`，检查 Node / npm / 脚本 / Astro 依赖，显示状态、日志和实际本地地址；可停止本次进程并在系统浏览器打开。当前文章按博客 slug 规则打开站点页面 |
| 新建草稿 | 标题必填，标签 / 单分类 / 摘要可选；写入 `src/contents/drafts/`，不写 draft 字段，同名加序号，创建后进入草稿并打开 |
| 删除文章 | 列表每行右侧的竖排三点菜单提供删除。必须再确认一次才从磁盘删除该文件；取消不改文件。不提供应用内恢复 |
| 文章统计 | 正文、草稿、AI 日报数量，以及正文和草稿的分类 / 标签排行。点击进入同一口径的列表。只读，不表示已发布或访问量。说明见 [文章统计](STATS.md) |
| 本地状态 | Git 只读状态，刷新，失败原因与异常文件提示 |
| 外观 | 浅色 / 深色 / 跟随系统，持久化 |
| 服务契约 | 新建、源码保存、编辑恢复、外部编辑器和本地预览已接入专用 IPC；资源、删除恢复、生产构建、Git 写操作与发布仅为后续契约 |

未实现：克隆、属性可视化编辑、删除后的应用内恢复、图片管理、自动保存到文章文件、外部文件监听、生产构建、月度趋势、热力图、访问量、Git fetch / commit / merge / push、部署状态接入、安装包完整验收。这些功能没有假按钮或模拟成功。

AI 日报不支持新增，不规划专用编辑表单；已有文件使用同一源码编辑器，也可以用外部编辑器打开。下一项为图片与写作完善。

保存直接使用编辑后的原始源码，未编辑部分的 BOM、换行、注释、自定义 Frontmatter 与 MDX 保留；属性栏显示已保存版本，修改属性目前需编辑源码。编辑器里的基础预览不执行 HTML / MDX / import，不加载图片或打开链接。完整站点效果使用顶栏「本地预览」，说明见 [本地预览](PREVIEW.md)。编辑恢复在停止输入 600 ms 后写入客户端目录，不等于保存文章；异常退出前尚未写入恢复记录的最后输入无法保证恢复。细节见 [编辑与恢复](EDITOR.md)。

正文、草稿和日报由目录区分，互不替代。`post` 里即使写了 `draft: true` 仍是正文，`drafts` 里即使是 `draft: false` 或没有该字段仍是草稿。正文不表示已经发布到线上。新建文件名兼容 Windows，标题中的路径分隔符不作为目录处理；写入前复核当前项目及草稿目录，拒绝目录链接。目录不存在时，只在已授权项目内创建 `src/contents/drafts`。先完整写入并同步临时文件，再用不覆盖目标的硬链接完成创建，因此需要支持硬链接的文件系统（本机 NTFS 已验收）。不改写已有文章里的 draft 字段，也不按该字段批量搬迁文件；客户端没有自动提交或推送博客的能力。
