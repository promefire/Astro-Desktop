# 当前功能状态

本文件描述当前交付；最新开发顺序与需求取舍见 [ROADMAP.md](ROADMAP.md)。

| 模块 | 当前范围 |
| --- | --- |
| 项目初始化 | Electron / React / TypeScript strict / Vite / Tailwind，Main / Preload / Renderer 分层 |
| 桌面 UI | 欢迎、文章、普通文章、草稿、AI 日报、项目设置路由，列表与只读详情 |
| 项目接入 | Windows 原生目录选择，Astro / collection / Git 检查，最近项目及恢复 |
| 内容读取 | 真实递归 MD / MDX，Frontmatter、日期、类型、分类、标签及诊断 |
| 日报 | 独立 summary / highlights / tools / tags；无草稿控制 |
| 浏览 | 搜索、分类 / 标签筛选、排序和分页；源码只读，资源管理器定位 |
| 新建草稿 | 普通文章标题必填，标签 / 单分类 / 摘要可选；真实写入 post 目录且 draft: true，同名加序号，创建后进入草稿并选中 |
| 本地状态 | Git 只读状态，刷新，失败原因与异常文件提示 |
| 外观 | 浅色 / 深色 / 跟随系统，持久化 |
| 服务契约 | 编辑、资源、恢复、预览、Git 写操作与发布接口，尚无实现 |

未实现：克隆、环境版本探测界面、已有文章编辑 / 删除 / 恢复、CodeMirror、Markdown 渲染预览、外部编辑器、图片管理、自动保存、外部文件监听、Astro 进程控制、文章统计、Git fetch / commit / merge / push、部署状态接入、安装包完整验收。这些功能没有假按钮或模拟成功。

AI 日报不支持新增，不规划专用编辑表单。下一项完成 CodeMirror 主区三种布局、保真编辑、防冲突保存与恢复，再按计划增加外部编辑器、npm run dev 本地预览和简洁统计。

新建文件名兼容 Windows，标题中的路径分隔符不作为目录处理；文件写入前复核当前项目及普通文章目录，拒绝目录链接。先完整写入并同步临时文件，再用不覆盖目标的硬链接完成创建，因此需要支持硬链接的文件系统（本机 NTFS 已验收）。不创建 `_drafts` 目录，不改写已有文章；客户端没有自动提交或推送博客的能力。
