# Astro Desktop 开发计划

更新：2026-10-12。以用户已确认意见为准；完成状态见 FEATURES.md，验证记录见 TESTING.md。

## 已确认的产品决定

- 文章属性留在右边栏。主工作区使用 MarkText Muya 内核（@muyajs/core）作为唯一内置编辑模式；编辑正文，保存时拼回原始 frontmatter。
- 参考 HexoHub 的创建弹窗、编辑器模式、外部编辑器入口和预览进程交互，保留 Astro Desktop 现有视觉风格及 Electron 安全边界。
- 新建只支持草稿文章：标题必填，标签、单个分类和摘要可选。存放在 `src/contents/drafts/`，不写入 `draft` 字段。正文是 `src/contents/post/`，日报是 `src/contents/ai-daily/`。类型由目录决定，Frontmatter 的 `draft` 不改变列表，正文也不表示已经发布到线上。2026-10-12 纠正了此前按 `draft: true` 放在 post 目录的做法；不批量搬迁历史文件。
- AI 日报保留真实读取与原始字段展示，不提供新增，不制作专用编辑表单。原始需求中的日报新建 / 专用表单规划已取消，后续也不单独开发一套日报编辑器。
- 本地站点预览按钮执行所选博客的 `npm run dev`，保留脚本前置步骤。检查 Windows 的 Node / npm、PATH、项目依赖和端口，展示真实启动输出、失败与停止状态；只停止客户端自己启动的进程。
- 文章统计采用用户已选择的「简洁概览」：普通文章、草稿、日报数量，以及分类、标签排行。统计本地文件，不表示网站访问量或真实部署次数。
- 每项独立功能完成后更新文档、检查 diff、运行相关检查 / 测试 / 构建，再 commit 并 push 到 Astro Desktop 仓库。原始博客不在开发提交 / 推送授权范围内。

## 实施顺序与验收

| 顺序 | 交付 | 验收重点 | 状态 |
| --- | --- | --- | --- |
| 1 | 项目接入、真实内容读取与桌面框架 | 普通文章 / 日报真实数据，最近项目，准确元数据和异常反馈 | 已完成 |
| 2 | 新建普通文章草稿 | 标题必填，单分类 / 标签 / 摘要，同名不覆盖，创建后出现在草稿，失败保留表单 | 已完成 |
| 3 | Muya 与安全保存 | 主区 Muya 正文编辑，frontmatter 分离；保留未知 frontmatter、注释、换行和 MDX；revision 冲突检测、原子保存、未保存退出保护和恢复 | 已完成 |
| 4 | 外部编辑器 | 用 Windows 为 .md / .mdx 设置的默认程序打开当前文章，不要求手动选择；处理未保存缓冲区与外部改动 | 已完成 |
| 5 | 真实本地预览 | `npm run dev` 环境诊断、日志、运行 / 失败 / 停止；依据博客路由打开目标文章 | 已完成 |
| 6 | 简洁文章统计 | 正文、草稿、日报按目录分开计数；正文和草稿的分类 / 标签排行，明确缺失和无效字段口径，刷新后更新 | 已完成 |
| 7 | 图片与写作完善 | 图片导入和发布到正文已完成；删除后的应用内恢复仍待做 | 进行中 |
| 8 | Git 同步与发布 | 选择文件提交、fetch / 安全整合远端日报、冲突停止、构建校验、显式推送、部署结果准确表达 | 待开发 |
| 9 | Windows 安装包 | 环境缺失提示、安装 / 卸载、升级、签名与发布验收 | 待开发 |

第 3 项中的 Markdown 预览只渲染安全 Markdown。MDX 的组件和 import 不在 renderer 中执行。完整站点效果使用第 5 项已完成的本地预览；两种预览在界面上分开说明。

未来属性表单编辑应通过 YAML AST 修改指定字段，不能重建整个文件而丢失注释 / 自定义字段。当前属性栏只读，用户直接编辑原始源码，因此不进行 YAML 重序列化。外部保存冲突时保留用户输入，提供重新加载与另存副本，不默认覆盖磁盘。

第 4 项已完成。外部编辑器使用系统默认打开方式，只打开磁盘上的当前文章，不监听文件变化。打开后编辑区暂停，用户重新加载后才恢复编辑；保存仍按 revision 停止覆盖。第 5 项已完成：本地预览执行当前博客的 `npm run dev`，用真实地址和可用性判断就绪，并只停止客户端本次启动的进程。第 6 项已完成：文章统计按目录计数，分类和标签只覆盖正文与草稿，点击后进入同一口径的列表。图片已可导入到文章同名目录，或在启用 S3/R2 时上传。草稿可以发布到正文目录：同时移动文章和同名图片目录，共享图片改为复制。内容目录变化会刷新索引。删除后的应用内恢复仍属于第 7 项。第 7–9 项继续按序开发，不添加未实现按钮。右侧只展示保存后的属性。

## 统计方案备选记录

1. 简洁概览：数量、分类 / 标签排行。**用户已选择。**
2. 概览 + 月度趋势：上述内容加按 `published` 日期汇总的月度文章分布。
3. 写作分析：再增加日期热力图与正文篇幅分布。

日期趋势与热力图不等于实际写作活动记录；如将来选用，必须标注日期来源。暂不实现后两种方案。
