# 文章统计

侧栏「文章统计」只读取当前项目已经成功索引的本地文件。它不写文章、不执行博客脚本，也不请求远程分析服务。数量不表示已经发布，也不表示访问量。

## 口径

| 项目 | 来源 | 说明 |
| --- | --- | --- |
| 正文 | `src/contents/post` | 即使 Frontmatter 含 `draft: true` 也计入正文 |
| 草稿 | `src/contents/drafts` | 即使是 `draft: false` 或没有 `draft` 字段也计入草稿 |
| AI 日报 | `src/contents/ai-daily` | 与正文、草稿互斥 |
| 分类排行 | 正文和草稿 | 沿用单分类。没有填写 category 的显示为「未分类」，和名为「未分类」的分类分开 |
| 标签排行 | 正文和草稿 | 一篇文章里的重复标签只计一次。大小写或名称不同的标签不合并 |
| 无标签 | 正文和草稿 | 单独计数，不制造「无标签」这个标签参与排行 |
| 无效字段 | 正文和草稿 | `category` 不是字符串时，不计入分类排行，也不算未分类。`tags` 不是字符串数组时，不计入标签排行，也不算无标签 |
| 读取失败 | 扫描问题 | 不进入数量和排行，并在页面上说明 |

AI 日报不进入分类和标签排行。排行按数量从高到低，数量相同再按名称稳定排序。超过一页时可以搜索和翻页，页码写明总数，不会只留下前几项。

## 联动

- 点击三项数量，进入对应目录的列表，并清除搜索和分类 / 标签筛选。
- 点击分类、标签或「无标签」，进入正文与草稿的联合列表，筛选结果数量与统计相同。名为「未分类」的分类和未填写 category 不会互相包含。
- 列表页的「清除筛选」恢复该范围的全部文章。
- 编辑器有未保存修改时，离开统计或列表仍会提示保存、放弃或取消。未保存的输入不计入统计。
- 新建草稿和成功保存会立刻按保存后的元数据更新。磁盘上的外部改动要等现有的「刷新」重新读取后才进入统计。
- 切换项目会先清掉上一份索引。过期的读取结果不会覆盖新项目。

统计页显示当前项目、路径、索引更新时间和统计范围。读取不完整时保留已成功的数量，并列出失败项。
